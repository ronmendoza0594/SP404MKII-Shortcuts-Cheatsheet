## DOOM OS

**DOOM OS v0.7.4, build 651C**, based on Roland firmware 5.52.

[Klangfeld Labs manual](https://klangfeldlabs.com/doom-os/manual/) · [Release notes](https://klangfeldlabs.com/doom-os/changelog/)

### Basics

| Combination | Function | Description |
| --- | --- | --- |
| `hold [REMAIN] + press [SUB PAD]` | Open DOOM OS | Enter the step grid from any SP-404MKII screen. |
| `[EXIT] (hold if configured)` | Exit DOOM OS | Save changes and go back to the Roland interface. |
| `[SHIFT] + [PAD 13] › SYSTEM › DOOM OS › Boot to DOOM › YES` | Boot straight into DOOM OS | Open the DOOM OS grid automatically at power-on. |
| `any [BUTTON] or [PAD]` | Wake the screen | Dismiss the screensaver. The first press only wakes the display. |
| `hold [SHIFT] for 3 s › use the control` | Inspect a control | See what a button, pad or knob does on the current screen. Press EXIT or hold SHIFT for 3 s to leave Help. |
| `[SHIFT] + [PATTERN SELECT]` | Undo the last edit | Go back up to 11 edits. Large patterns can exceed the undo capacity. |
| `[REMAIN] + [PATTERN SELECT]` | Redo an edit | Reapply an edit that was undone. |
| `[PATTERN SELECT]` | Start or stop the pattern | Toggle pattern playback. |
| `hold [PATTERN SELECT] + tap its [PAD]` | Select a pattern | Queue the next pattern during playback. When recording is active, the change is immediate. |
| `hold [PATTERN SELECT] + [SUB PAD] + tap its [PAD]` | Switch patterns immediately | Jump straight to another pattern while the sequencer is running. |
| `hold [PATTERN SELECT] + tap an empty [PAD]` | Create an empty pattern | Use an unused pattern slot for a new sequence. |
| `hold [PATTERN SELECT] + [BANK]` | Choose a pattern bank | Choose the bank used for pattern selection. |
| `[SHIFT] + [PAD 11] › turn and press [VALUE]` | Adjust tempo directly | Open tempo, set the BPM and confirm. |
| `[RECORD SETTING] twice › BPM` | Adjust tempo in the pattern panel | Change the BPM from the pattern settings. |
